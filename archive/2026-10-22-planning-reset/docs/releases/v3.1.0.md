# Expert Chat v3.1.0

本次更新加入完整的学习中心，并将长文件后台任务、文档编辑与格式转换统一到一个可自建的 Expert Chat Gateway。

## 学习中心

- 新增独立「学习」入口，提供 AI 导师、课程学习、智能刷题和复习卡四条完整路径。
- AI 导师支持选择教学风格，并可在学习对话中生成小结、练习题和复习卡。
- 课程支持 AI 生成树状大纲、逐节点学习、进度记录与继续学习。
- 智能刷题支持结构化题目、即时判定、解析以及错题归档。
- 新增错题本与间隔复习调度，记录复习次数、难度和下次复习时间。
- 学习会话使用独立模式和提示词组装，并与普通聊天、故事模式隔离。

## 统一文件 Gateway

- 一套 Gateway 地址和 Token 统一承载长文件分析、文档编辑与格式转换。
- 新增 `/v1/capabilities` 能力发现，客户端根据服务端清单显示可用能力。
- 长文件任务在服务端持久化运行；应用退到后台或关闭后任务继续，重新打开后补齐进度与输出。
- 任务创建支持幂等请求、增量事件、取消和服务重启后的恢复排队。
- 文档编辑与格式转换模块挂载到同一 FastAPI 进程，保留模块化路由边界。
- 新增 Gateway 模块注册表，后续 OCR、知识库等服务按统一协议扩展，不再增加第二套地址和 Token。
- 旧版长任务和文档服务设置会自动迁移到统一 Gateway 配置。

> 当前版本 Gateway 仍使用部署者配置的共享访问 Token；多账户 OIDC 与账户数据隔离尚未包含在本版本中。

## 交互与稳定性

- 长任务消息显示实时进度、状态说明和取消入口。
- 学习入口、会话徽章和窄窗口布局完成响应式适配。
- 文档处理统一使用 Gateway 错误提示和能力判断。
- 补齐学习数据迁移、课程、刷题、复习、Gateway 协议和后台恢复测试。

## 自建 Gateway

服务端源码位于 `server/gateway` 和 `server/doc_edit`。Docker 构建应从 `server` 目录执行：

```bash
cd server
docker build -f gateway/Dockerfile -t expert-chat-gateway .
```

完整配置和扩展规则见 `server/gateway/README.md` 与 `docs/gateway-architecture.md`。
