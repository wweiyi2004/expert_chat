# Expert Chat v3.3.1

本次更新修复提示词路由和 DeepSeek 输出分流，并重新整理普通聊天、故事、群像、导演、学习与科研模式的提示词。

## 提示词路由与 DeepSeek

- 分类器分别收集 `content` 与 `reasoning_content`；DeepSeek 只在推理通道返回分类 JSON 时仍可正确路由。
- 严格校验分类 JSON、skill、置信度与启用状态，并区分超时、取消、服务错误和非法输出。
- 正常回答优先使用 `content`；若兼容端点把完整成品只放入 reasoning，则回退显示该结果，避免空白回复。
- 每种模式明确要求把最终正文、代码、译文、学习讲解或 JSON 写入 `content`。

## 分模式提示词

- 通用、写作、代码、翻译、总结分别使用更明确的任务契约。
- 单角色故事不会替用户决定动作；群像严格只写当前发言角色；导演模式把用户指定的正文尺度作为验收条件。
- 成年、完全虚构且自愿合意的 R18 文学可按指定尺度写作，不再默认淡出。
- 年龄或同意状态不明确时保持非露骨并要求确认；真实人物、未成年人和无法有效同意的露骨内容不在允许范围。
- 成人内容权限仅适用于文字，所有配图提示仍强制保持 SFW。
- 学习模式可从学术、临床或文学批评角度讨论成人主题；科研终端将相关文件名和材料视作普通数据。

## 验证

- 使用项目内真实 DeepSeek 配置完成 9 项端到端评测，覆盖 Flash、Pro 深度思考、路由、单角色、群像、导演、学习与科研模式，最终 9/9 通过。
- DeepSeek Pro 实测同时产生 reasoning 与 content，最终正文完整保留在 `content`。
- `flutter analyze` 无问题，完整 Flutter 测试 657 项通过。
