# Expert Chat v3.7.1

- 默认联网搜索切换为 DeepSeek Search / Fetch，原 DuckDuckGo 配置自动迁移，搜索及重试不再自动回退到 DuckDuckGo；官方 DeepSeek 连接复用模型 Key。
- 更新 DeepSeek Flash 模型名称及视觉能力，保留 Pro 与推理强度选择，旧官方 Flash 别名自动迁移。
- 深度思考、智能搜索、思考档位移至输入框上方；发送与语音合并，按输入内容切换，附件与操作按钮缩小。
- 推理强度通过带背景虚化和过渡动画的滑块弹窗调整，未开启深度思考时禁用。
- 普通聊天顶部保留聊天 / 工作切换，新会话按钮移到左侧；提示词、大纲、导出和记忆操作移至“+ → 会话操作”。
- 设置首页返回聊天，保留桌面侧边栏和草稿；调整窗口尺寸时保留页面状态。
- 明确固定提示词预设与自动技能路由的优先关系，补充聊天和工作的用途与执行差异。

本版为新的 Shorebird 基座 `3.7.1+4111`。Android 沿用 `com.wweiyi.expert_chat` 与原正式签名；Windows 解压完整 ZIP 后运行，保留同目录依赖文件。旧版安装包需完整覆盖安装本版，之后才能接收本基座的后续热更新。

发布验证与产物哈希记录于 `output/releases/v3.7.1/`。模拟接口验证不能替代真实 DeepSeek 账号调用；本次未进行 Android 真机覆盖升级及厂商后台策略验收。
