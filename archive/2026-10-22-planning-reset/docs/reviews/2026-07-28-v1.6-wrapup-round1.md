## P0 — 收口前建议必修

### 1. Android release 仍用 debug 签名
- **Where**: `android/app/build.gradle.kts` release `signingConfig = debug`
- **Why**: 与应用内 OTA/`REQUEST_INSTALL_PACKAGES` 叠加后信任链薄弱；换正式证书后在野包无法覆盖安装
- **Fix**: 正式 keystore + `key.properties`（不入库）；CI 校验非 debug 指纹；文档说明 debug 用户需卸载重装

### 2. 篇幅预算 `remaining ∈ (0, 200)` 时 clamp 抛错
- **Where**: `lib/domain/story/story_length_budget.dart`（约 80–82）
- **Why**: `clamp(200, remaining)` 在 lower>upper 时 `ArgumentError` → UI/发消息崩溃
- **Fix**: 安全夹取；补测 remaining=1/50/199/200/899

### 3. 更新选包 ABI 回退过宽
- **Where**: `lib/domain/update/app_update.dart` pickAsset 末尾任意 `.apk`
- **Why**: 现 Release 常只发 arm64；v7a 设备会下到 arm64 包
- **Fix**: miss 后仅允许 `universal`，否则 null → 浏览器/提示无适配包；补测

### 4. 跨会话全局 `error` / 重试对象错误
- **Where**: `chat_controller.dart` + `chat_page.dart` 错误横幅
- **Why**: A 失败横幅画在 B；重试可能 regenerate 当前会话 B；生图失败常无法重试
- **Fix**: error 绑定 convoId；重试针对失败会话；生图专用 retry

## P2 — 建议记入技术债 / 下一小版

- OTA 下载无 SHA256/证书预校验  
- 纯生图路径未跑 `ImagePromptSafety`（与配图策略不一致）  
- 多选分享忽略图片附件  
- 大图远程拉取无上限/无 cancel；列表持有全量 base64 内存  
- 大纲 AI 生成未注入总字数目标  
- `authorNote` 扁平化可被情节面板一键清空硬约束  
- `loadAll` 全量内存；ToolEnginePool 只增不减  
- profiles JSON 损坏时覆盖成空列表  
- `dart:io` 无条件 import 挡住 web 编译  
- Windows 关闭 semantics 无障碍 workaround 无 issue 跟踪  
- Shorebird/`SHOREBIRD.md` 与「仅 arm64 发包」文档不一致
