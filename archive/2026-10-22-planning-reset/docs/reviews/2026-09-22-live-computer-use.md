# 真实模型 Computer Use 验证

日期：2026-09-22。模型使用应用当前配置的 `deepseek-v4-flash-vision-exp`，通过原有安全存储取得凭证，只在本次子进程环境中传递，没有写入代码或报告。

## 测试范围

使用真实模型 API、真实 Cua Driver 0.28.0，以及项目生产代码中的 `OpenAiCompatibleProvider`、`McpClient`、`ComputerUsePolicy`、`DocumentServiceClient`、`ToolCallRunner` 和任务预算组件。测试窗口提前准备好，模型自主决定观察、编辑和保存步骤。

这次不是 ChatPage 原生界面端到端测试。为了避免把记事本其他标签页的信息发送给模型，测试适配器限定到唯一测试文件对应的窗口，只提供编辑区及文件/保存菜单的 UIA 文本与元素标识，移除截图及其他标签页内容。因此它证明了真实模型使用 UIA 工具完成受限任务的能力，不代表截图视觉定位已经通过真实模型验证。

模型先读取窗口，自主完成内容替换。后台 Ctrl+S 被驱动拒绝后，它重新观察，展开“文件”菜单，找到并点击“保存”。测试没有替模型预先编排这一菜单操作路径，也没有允许它转为前台输入。

有 3 次工具请求被拒绝：2 次来自测试的额外限制（只允许 Ctrl+S、只接受当前允许的 element_token），1 次来自驱动对后台 Ctrl+S 的拒绝。这些不等于 3 次真实桌面误操作。模型最终使用的新控件观察完成了保存。

模型的 `verify_state` 请求得到 unknown，最终回复明确保留了“未直接见证磁盘落盘”的限制。测试程序随后独立读取文件，确认实际保存成功；不能把测试程序的证据说成模型自己已取得的证据。
