日常 Agent

一个帮你处理日常琐事的 Agent：订票、记账、写周报、查资料。它能做什么，由你用几块积木拼出来，而不是由开发者预先写死。

一个入口

聊天、工作、学习、创作都放在同一个对话里。区别在于对话里挂了哪个助手、哪些技能，不靠切换模式。

能力是积木

触发、助手、技能、输出四种积木，组合起来就是一条自动化。所有积木都能复制、改动、导出分享。

你定规矩

每个工具都有三档权限：自动、询问、禁止。确认时可以顺手改成以后自动，权限越用越贴合你的习惯。

能力模型

所有自定义都落在四种积木上

用户不需要理解 MCP、system prompt、subagent 这些概念。在界面上只看到四种颜色的积木，颜色在整个 App 里含义固定。

触发

什么时候开始

  • 我发消息
  • 定时：每周日 20:00
  • 分享到 App：图片、链接
  • 通知、位置、文件变化
→
助手

谁来做

  • 模型 + 备用模型
  • 性格与说话方式
  • 可用的工具和技能
  • 记忆范围
→
技能 / 工具

怎么做

  • 内置：日历、文件、浏览器
  • 连接：MCP、HTTP API
  • 技能：多步配方，可用 /命令调用
→
输出

结果去哪

  • 回复到对话
  • 写入笔记、表格
  • 推送通知
  • 首页小组件
权限横跨所有积木：每个工具 自动询问禁止，还可以设金额、频率、路径上限。

自定义的层次

同一个 App，深浅三层

自定义能力强，不等于第一眼就看到所有开关。每一层都能从上一层自然点进去，普通用户永远不会被迫看到 JSON。

层次谁会用能改什么入口
随手调所有人首页小组件排序、快捷技能、主题和字号、审批时点「以后不再询问」长按、审批卡、首页「编辑」
拼积木愿意折腾的人新建助手（性格、模型、工具、记忆）、技能步骤、定时和分享触发、权限上限右栏配置、技能编辑器、一句话生成
写代码开发者接 MCP / HTTP 工具、技能里插脚本步骤、导入导出 .skill、Hook、远程电脑执行设置 › 连接、技能步骤「脚本」
