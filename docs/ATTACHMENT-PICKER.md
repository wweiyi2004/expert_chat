# 统一附件选择面板

聊天输入区的“上传文件”“上传图片 / 参考图”“素材库”共用 `AttachmentPicker`，分别默认打开最近使用、图片、素材库分类。宽窗口显示居中对话框，手机显示底部面板。

## 选择体验

- 最近使用：按素材库的 `lastUsedAt` 倒序展示最近添加或使用的 24 项，不读取操作系统的全局最近文件记录。
- 图片：图片缩略图、勾选和预览。
- 文档：支持的文档列表和文字预览。
- 素材库：按名称排序的全部可用素材。

搜索作用于当前分类，切换分类和修改搜索保留勾选；所有分类共用选择数量上限。预览返回后保留选择。素材库加载失败提供重新加载入口，仍可浏览本机文件。

“浏览本机文件”打开系统原生选择器，按当前分类设置文件类型。取消系统窗口后停留在面板中并保留勾选；成功选择后，已勾选的素材与本机文件一起交给聊天输入区。手机额外提供相册入口，沿用现有相册权限与系统选择器回退。

## 能力与导入

普通聊天按模型视觉能力开放图片选择。独立生图模式只允许图片，数量受模型参考图上限约束。原生选择器返回的扩展名也会校验，防止通过手动输入文件名绕过分类限制。

面板只返回 `FileIngestSource`，不直接修改聊天附件。素材库字节、系统文件和相册图片都通过 `AttachmentIngestor` 执行原有容量检查、文档解析与图片准备，避免素材库入口跳过解析或容量限制。无法读取的素材按既有导入规则提示并跳过。

系统选择及相册图片保留输入区的图片确认步骤；在面板中勾选并确认的素材图片直接添加。所有异步操作继续绑定打开面板时的输入区序号，切换会话后迟到结果失效，旧任务不会解除新任务的忙碌状态。

## 验证

新增 14 项面板测试覆盖排序、搜索、跨分类选择、模型限制、剩余名额、取消、失败重试、预览、销毁及迟到结果。布局覆盖桌面、320 像素手机、矮窗口和手机软键盘。

新增 2 项页面测试验证素材库选择经过解析，以及切换会话后确认旧面板不会添加附件。原有附件流程测试已更新为通过统一面板调用系统选择器。

可用 `flutter test --no-pub test/attachment_picker_test.dart --dart-define=EXPERT_CHAT_RENDER_PICKER=true` 在 Windows 上生成本地布局截图（使用测试素材及本机字体），输出到被忽略的 `output/attachment-picker-*.png`。自动化测试替代系统选择器，不代表真实文件窗口或手机权限弹窗已完成实机验收。
