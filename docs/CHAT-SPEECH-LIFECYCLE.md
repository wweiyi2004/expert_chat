# 聊天语音生命周期

录音、识别文本合并、朗读状态和异步会话管理已从聊天页面抽入 `ChatSpeechController`。页面通过状态监听更新按钮，提供云端识别配置、朗读参数及提示展示，转发应用生命周期和会话切换事件。

## 职责与所有权

- `ChatSpeechController` 管理系统/云端识别选择、忙碌与录音状态、识别回调有效性、麦克风与扬声器互斥、朗读错误提示去重。
- `SpeechInputService` 保留平台识别、语言选择和原生状态处理；`MimoSpeechInputService` 保留录音、上传、时长及文件限制；`TextToSpeechService` 保留合成和播放协议。
- 输入控制器由页面拥有，语音服务由 Provider 拥有。页面销毁时协调器解除监听、分离回调并请求停止，不销毁共享服务或输入控制器。

## 识别行为

系统识别保留录音开始时的光标选择，部分结果替换同一段文本。系统每个短句的最终结果不会关闭连续听写；只有停止状态、取消或错误结束录音显示。

云端识别仍通过第二次点击结束录音并上传，上传期间再次点击可以取消。最终结果插入当前光标，保留上传期间用户输入的内容；最终结果消费后使该会话回调失效，防止重复插入。配置失效时取消录音并提示重新开始。

识别不会自动发送消息。已经识别到文字后的无匹配或超时错误仍安静结束，其他错误保留原有提示，并请求清理录音。

## 异步顺序与取消

录音意图在等待朗读停止之前登记，阻止快速连点创建重复初始化。后续每次异步返回和结果/状态/错误回调均检查识别会话序号。

新识别必须等待前一次初始化、启动或云端上传返回，以及已请求的原生取消完成。旧启动即使迟到成功，也先完成自身清理，之后才允许新录音获取服务；旧清理不会取消新录音。

朗读同样检查操作序号，并在麦克风取消完成后开始。连续选择多条朗读请求时只执行仍有效的最新请求。切换会话取消识别、停止朗读并使等待中的语音操作失效，避免旧操作在新会话启动。已排队的旧朗读错误提示也随之失效。

权限弹窗导致的短暂 `inactive` 状态仍允许首次初始化继续；真正进入后台的 `paused`、`hidden` 等状态会取消。停止与页面销毁使迟到识别文本失效。

## 验证

新增 19 项协调器测试覆盖光标替换、连续听写、旧回调、错误清理、权限与后台切换、重复点击、延迟启动与取消、新旧云端上传交错、朗读互斥与请求选择、提示去重和销毁。

新增 2 项页面集成测试验证切换会话后不接受旧识别文字，并停止原会话的回复朗读。原有语音服务与页面交互测试继续运行。测试使用替代麦克风、播放及云端服务；系统权限窗口、真实音频设备和远端服务仍属于实际运行验收范围。
