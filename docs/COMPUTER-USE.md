# Windows 电脑操作

第一版在现有任务模式中加入本地 MCP 与 Cua Driver。普通聊天不会暴露电脑操作工具；任务必须选择对应服务。手机虚拟副屏不属于本次改动。

## 使用

1. 安装官方 Cua Driver 0.28.0 Windows x64 独立程序。本项目提供 `scripts/install_computer_use_driver.ps1`，下载固定版本并验证 SHA-256，不运行上游安装脚本、不注册系统服务或开机任务。当前开发电脑已准备好。
2. 设置 → 能力 → 自定义 MCP 服务器 → 添加 MCP 服务器 →「填入 Cua Driver 电脑操作配置」。默认路径为 `%LOCALAPPDATA%\ExpertChat\drivers\cua-0.28.0\cua-driver.exe`，参数每行一个：`mcp`、`--direct`。也可用文件选择器指定路径。
3. 保存，然后点击「发现工具」。服务显示「已发现 · 按需连接」。发现工具会运行指定程序；本地进程没有监听网络端口。
4. 在会话中选择该 MCP 服务，切换为「任务」模式，再描述目标，例如：打开记事本，在新的测试文档中写一段文字并保存。

推荐使用同时支持工具调用与图片输入的模型。非视觉模型仍可读取控件树，但不会收到截图像素。

## 执行规则

- 电脑操作使用 Cua Driver 的有限工具集：应用/窗口枚举、权限状态（不弹权限请求）、窗口观察与验证、应用启动、点击、文字与按键输入、滚动和拖拽。驱动原始目录中的进程结束、配置修改、剪贴板读取、录制、权限升级等工具不向模型开放。
- 每次动作必须指定 `pid` 与 `window_id`，且该窗口须在最近 90 秒内观察过。窗口内的定位仍由驱动校验当前 `element_token` / `snapshot_id`；截图坐标来自当前观察。一次动作使本地观察失效。
- 默认强制后台模式。仅当用户启用「允许必要时切换前台」，并且之前该窗口的后台操作收到明确拒绝时，模型才可请求前台模式。不会静默重试为前台。
- 每个界面动作后自动重新获取同一窗口的控件树及截图，供模型核验。自动回读证明观察成功，不等于业务目标已经完成；模型仍需判断实际内容、状态或文件结果。
- 结果不明确时停止自动重放该动作，返回“操作可能已执行，但无法核验结果”。再次继续应先观察现场，不能重复提交、发送或购买。
- 点击停止会取消当前请求，关闭应用持有的本地 MCP 连接；运行中的已送达动作无法撤销。任务结束也释放电脑驱动。再次发起任务会重新连接和观察。首版没有持久化桌面任务的自动续跑。
- 截图回传限制为单次一张 PNG/JPEG/WebP、8 MB 以内；模型当前请求仅保留最新工具截图，普通用户附件不受此淘汰规则影响。
- 以上是应用执行约束，不是操作系统沙箱。模型可见的屏幕内容会发送给所配置的模型服务。重要提交前应让用户核对，登录与付款交回用户。

## 本地 MCP

新增 stdio 传输，执行文件与参数分开传递，不经 shell 拼接。连接执行 `initialize` / `notifications/initialized`，协商 2024-11-05、2025-03-26、2025-06-18 或 2025-11-25；支持分页工具发现。现有 HTTP 文档服务协议保持原流程。

同一程序配置复用连接。进程退出、无效输出、请求超时或取消会终止连接；工具动作不自动重试，后续用户请求可以新建连接。关闭、删除、修改服务器配置时清理本地连接。导入 API 配置中的本地程序默认关闭、清空发现缓存，需用户手动启用并重新发现；参数不应放密钥。

本地连接仅支持 Windows/macOS/Linux，Windows 电脑操作预设针对 Windows x64。第三方程序自行启动的外部常驻服务不属于本应用的生命周期；Cua 预设使用 `--direct` 使本应用持有实际执行进程。

## 验证

自动测试包含 stdio 初始化与分页、真实子进程通信、取消/超时/进程退出、协议拒绝、配置迁移、后台权限约束及聊天中截图传入下一轮、旧截图淘汰等。

只读驱动验证：

```powershell
dart run tool/computer_use_probe.dart "$env:LOCALAPPDATA/ExpertChat/drivers/cua-0.28.0/cua-driver.exe"
```

显式的记事本实机测试（会打开测试文件、写入、保存）：

```powershell
dart run tool/computer_use_probe.dart "$env:LOCALAPPDATA/ExpertChat/drivers/cua-0.28.0/cua-driver.exe" --smoke-notepad
```

输出在 `build/computer-use-smoke/`。同时检查 UIA 回读、磁盘文件、焦点和鼠标位置。驱动启动和工具验证不调用真实模型 API；聊天执行链路另有模拟模型集成测试，不能把它描述为完整的真实模型端到端任务成功率。

2026-09-22 已补充一次受限窗口的真实模型测试：DeepSeek 自主决定 UIA 操作，完成记事本文字替换和菜单保存，并由测试程序读取磁盘核验。详见 [真实模型验证记录](reviews/2026-09-22-live-computer-use.md)。它不包括 ChatPage UI 或截图视觉定位的真实模型端到端验收。
