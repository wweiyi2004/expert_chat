# 会话侧栏与历史导航

侧栏从 `chat_page.dart` 拆出，桌面工作区与手机抽屉继续共用同一个 `ChatWorkspaceSidebar`。原页面保留该组件的导出，现有调用方无需调整。

## 职责

- `ChatWorkspaceSidebar` 连接会话状态与导航，管理重命名输入和删除确认。
- `ConversationHistoryList` 展示历史列表、匹配摘要、选中状态与行内操作，通过回调提交用户操作。
- `ConversationModeFilter` 展示现有“全部 / 对话”筛选。
- `ConversationSidebarController` 管理搜索防抖、结果、失败重试和模式筛选，不依赖页面布局。
- 会话的加载、重命名和删除仍交给 `ChatController` 与仓库处理，侧栏不直接改写持久化数据。

## 搜索与异步顺序

输入先去掉首尾空白，再按 250 毫秒防抖发起全文搜索。每次关键词变化立即使此前请求失效，包括新请求尚未开始的防抖期间。旧请求的成功或失败都不能覆盖最新结果。清空输入恢复历史列表；组件销毁取消计时器并忽略迟到结果。

搜索期间显示“正在搜索…”，失败后显示重试入口。模式筛选与搜索结果取交集，不额外发起搜索。

选择历史结果会等待会话正文加载完成，再发布消息定位请求。`ChatController.selectConversation` 检查选择序号和等待前的当前会话，防止旧加载覆盖后续选择、新建会话或删除后的自动选择。侧栏还检查导航序号，避免旧操作发起消息跳转或重新打开已离开的聊天工作区。

## 重命名与删除

重命名去掉首尾空白，空标题不提交。删除确认始终绑定打开弹窗时的会话 ID；取消不删除，确认后等待控制器处理。删除当前会话、删除最后一个会话以及删除失败恢复列表，沿用控制器已有行为。

## 验证

新增 17 项测试：6 项搜索状态测试和 11 项侧栏集成测试，覆盖防抖、旧结果与旧错误、清空、重试、销毁、筛选、重命名、删除取消及目标绑定、删除当前或最后会话、删除失败恢复、延迟加载定位、快速切换、新建与离开工作区。

原有响应式布局测试和全量 Flutter 测试一并执行，本轮结果为 1097 项通过、1 项原有跳过。搜索仓库在这些交互测试中使用可控替代实现；大规模真实历史数据的查询性能仍需实际运行验收。
