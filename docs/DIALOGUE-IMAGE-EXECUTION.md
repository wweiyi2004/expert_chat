# 对话配图执行

将普通对话/故事配图中的提示词准备、可选优化、媒体服务调用和附件转换独立为 `DialogueImageExecutor`。模型 `generate_image` 工具与非工具模型的预生成共用此模块。

## 职责边界

- 执行器接收配置、角色及本轮文字，复用 `ImagePromptSafety` 生成提示词，必要时调用注入的优化函数，调用媒体提供方，将返回结果转换为附件及提示词元数据。
- 控制器保留角色库读取、工具暴露、每轮成功次数限制、任务预算、会话活动更新、附件追加和生成版本记录保存。
- 执行器通过活动及生成状态回调报告进度；`onGenerated` 由控制器绑定本轮会话和助手消息，并按原顺序追加图片、等待版本记录保存，然后标记生图步骤完成。
- 工具参数解析移至 `DialogueImageExecutor.parseToolArgs`，正常调用和失败步骤重试共用，保留 `brief_hint` / `briefHint` 兼容与无效 JSON 回退。

## 保持的行为

1. 角色立绘只使用角色卡及简短补充提示，不混入用户故事正文或模型自由提示词，也不调用自由生图提示词优化。
2. 无角色时优先使用模型提示词，缺失时使用用户文字。优化失败后沿用原始净化描述，优化成功后再次执行原有提示词处理。
3. 工具路径不重复调用优化模型，不重复扣减工具次数。只有生图成功才占用本轮图片名额；失败后仍可重试，成功后后续调用返回原有的次数限制提示。
4. 开始、优化结束及媒体服务返回后保留取消/执行状态检查。取消后的迟到图片不进入附件追加或版本记录回调。
5. Base64、远端 URL、MIME 类型、估算大小、文件名及 API 修订提示词均按原有规则保留。生成状态在请求收尾时清除。

## 验证与范围

新增执行器测试覆盖提示词及角色隔离、优化回退、预算拒绝、取消、迟到结果、媒体失败重试、返回数据转换与参数兼容。新增控制器测试在同一轮执行三次生图调用：第一次失败、第二次成功、第三次被次数限制拒绝，最终仅保留一张图片。

既有角色配图、强制配图、纯生图、图片编辑、任务及页面测试继续运行。本次测试不调用远端生图服务。

独立生图、参考图准备和图片编辑已进一步整理，见[文生图、参考图与图片编辑流程](IMAGE-GENERATION-PIPELINE.md)。对话配图与独立生图共用 `ImageGenerationService` 的请求及附件转换，提示词优化共用 `ImagePromptOptimizer`；各入口仍保留自己的流程编排和状态更新。
