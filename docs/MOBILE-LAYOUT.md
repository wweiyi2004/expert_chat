# 手机界面适配

小于 600 逻辑像素的聊天界面使用整行编辑区，附件、深度思考、麦克风和发送按钮放在下方。输入最多展示三行，更多内容在输入区内滚动；原有发送、粘贴、语音及附件处理链路保持一致。

顶栏空间不足时，会话名放在「对话 / 任务」上方，长标题省略，避免原先直接隐藏标题。手机键盘弹出时收起底部导航，关闭键盘后恢复，当前页面及草稿保留。

HTML / SVG 预览的手机布局和边界见 [LOCAL-CODE-PREVIEW.md](LOCAL-CODE-PREVIEW.md)。网页版新增内嵌预览；桌面手机宽度支持 360、390、430 像素。

验证覆盖 320 / 360 / 390 像素、1.0 / 1.24 字体倍率、键盘遮挡、底部安全区、工具切换后的草稿保留以及桌面布局回归。可生成窄屏截图：

```powershell
flutter test --no-pub --dart-define=RENDER_MOBILE=true test/chat_responsive_layout_test.dart
```

截图输出到 `output/mobile-chat-*.png`。2026-09-15 全量测试 1125 项通过、1 项原有跳过；尚未进行 Android / iOS 真机触控和系统键盘验证。
