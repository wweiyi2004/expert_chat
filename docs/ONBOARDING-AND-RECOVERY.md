# 首次配置与错误恢复迭代（2026-09-07）

## 用户流程

- 首页在模型尚未配置时提供“连接模型，开始使用”。已有配置时显示可填入输入框的小任务示例，不自动发送。
- 设置 → 模型也提供连接引导入口。可选现有服务商预设或自定义 OpenAI 兼容地址，填写密钥和模型。
- 连接测试发送一条独立的简短消息；必须收到可见正文才显示成功。测试不携带聊天历史、附件、记忆或工具；最多等待 20 秒，可取消，不自动重试。实际服务可能产生少量用量。
- 测试成功后才显示“保存并开始对话”。更改表单使验证结果失效；取消和失败保留表单，保存成功回到聊天，已有草稿保留。
- 修改服务主机时清除原密钥，避免把原服务的凭证带到新主机。密钥写入系统安全存储，普通偏好中仅保存不含密钥的配置。
- 配置保存完成后才更新运行状态；普通保存异常会尝试还原已修改的设置和密钥，恢复失败时明确提示检查。

## 错误恢复

`AppFailure` 将密钥错误、权限不足、模型/地址不可用、额度不足、限流、网络、超时及本地存储错误转换为可操作提示。技术信息默认折叠，复制内容会隐藏已知密钥、常见凭证字段和 URL 中的登录/查询信息；网络异常的请求正文、响应正文和认证请求头不进入该诊断摘要。

`RecoveryNotice` 已接入聊天错误、设置读取、项目列表与编辑、生图记录与再次生成、备份操作。只给安全的操作提供重试；列表加载会清除旧错误，重试中阻止重复点击。文档修改、生图和备份导入保留原有的确认与恢复入口，不因统一错误界面而自动重放。
