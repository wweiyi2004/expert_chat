# Expert Chat 3.8.0+4112 使用入口

Windows：完整解压便携包后运行同目录的 `expert_chat.exe`，保留相邻 DLL、`data` 和 `expert-desktop.exe`。本次交付不会自动启动新版、替换或关闭正在工作的旧版；请等旧任务结束后自行切换，避免两个版本同时写同一份本地资料。

- **工作会话**：输入目标后可在运行中补充要求；补充有回执，下一完整工具轮生效。暂停会停止派发新轮次，已提交的系统命令仍可能继续。停止按当前任务及其子任务生效，不误停其他会话。
- **日志与工作台**：查看公开计划、摘要、版本、用量和真实工具状态；固定约束由用户编辑。历史检索/压缩保留原会话，未知副作用需先核验，不自动重放命令。
- **文件改动**：逐轮/逐文件/逐块审阅与版本核验回退；新建文本文件可以确认删除后从快照无覆盖重建。Shell、外部服务和未知二进制变更不承诺自动回滚。只有明确登记的文件/目录/归档进入最终交付清单。
- **设置 → 模型**：配置渠道、凭据、模型、渠道优先级和备用组。显式模型/组失效时需要重新选择，不擅自换模型。原有自定义系统指令保留；独立提示词预设不重新启用。
- **设置 → 能力**：按需工具、数学、监督和角色积累。数学、监督、模型角色验收及自动加入需要分别启用；默认不开启额外付费评审。数学依赖 Python/SymPy，可诊断并由用户启动可信安装。浏览器需要 Node/Playwright 等依赖；人工网页与受控浏览器为不同入口。
- **工具 → 远程电脑任务**（自动化在其内）：电脑独立宿主需自行配置、启动及配对；手机断线不等于宿主停止。旧 Flutter 本机任务不会自动迁移为独立宿主任务。远程账号命令不是本机 Rust 子目录权限沙箱。
- **Android 本机控制**：由用户在系统设置启用服务并在应用明确开启本次控制。模型不能自行授予权限；可用通知 STOP、应用停止或撤权立即阻止后续派发。
- **备份**：新增用户配置及会话工作记忆可备份；密钥、操作日志、可运行队列和控制租约不会作为自动执行状态导入。导入前需先结束或手动停止当前任务。

可选 Magpie 组件需要用户明确配置本机路径/依赖、手动启动并登录；没有静默账号发现或自动登录。真实订阅账号、付费模型质量/成本、厂商 Android 真机限制及发行渠道仍需用户实际环境验证。构建和测试证据见源码 `docs/PROJECT-PLAN.md` 的 3.8.0 逐项验收记录；验证日志不放入便携包。
