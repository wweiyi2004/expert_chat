本补丁修复数学工具及同类内置工具的步骤记录：新调用成功后保存正确的完成状态、工具名、调用身份、已脱敏参数和结果；失败、取消、拒绝、未执行和未知结果保留各自真实状态。计算后端与权限不变。

本轮仅提供 Windows 包；3.8.0 Android 和独立宿主包保持原样，没有重跑 Android 模拟器或生成新的 APK/宿主。完整校验见同目录 `SHA256SUMS.txt` 和 `release-manifest.json`，修复与验收记录见源码 `docs/PROJECT-PLAN.md` 第14节。
