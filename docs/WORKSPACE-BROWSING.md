# 第二轮：项目与素材浏览（2026-09-07）

## 项目工作区

- 桌面采用项目卡片与工作详情双栏；手机采用横向项目卡片，以及会话/资料切换入口。
- 优先显示当前会话所属项目，展示会话和资料数量；可按项目名称、说明查找项目。
- “继续最近会话”按会话更新时间定位，成功读取后才返回聊天。默认展示最近 5 个会话，可展开全部；新建与移入会话继续使用原有项目关联机制。
- 关联资料直接显示文件名和大小，可以进入文字预览并复制提取内容。预览在本地完成，沿用文件解析上限，检查文件 SHA-256，不向模型发送请求。
- 切换项目时清除旧资料，忽略迟到的读取结果，避免显示上一个项目的文件。

## 生图图库与对比

- 生图版本记录改为缩略图网格，可按原始描述、实际提示词或模型搜索。
- 同一系列由记录中的父版本关系决定，与相同提示词或相同图片字节无关；搜索筛选不会重新编号。
- 可从每张卡片进入同系列筛选。选择两张图片后，按选择顺序作为 A/B 并排查看；跨搜索条件保留选择，最多两张。
- 对比页高亮变化参数，可切换为只看变化。参考图按内容校验信息与顺序比较，忽略仅文件名称/本地存储编号的变化。
- 点击大图复用原有图片查看器，支持放大、保存和分享；图片缺失时仍保留参数记录与复制入口。
- 再次生成仍须确认费用，不自动重放请求；参数相同不代表生成图片相同。

## 素材选择

- 素材库新增名称搜索，在图片/文件分类之间切换时保留已选内容。
- 选用时按实际选择顺序读取素材；缺失文件明确报错，保留可调整的选择状态。
- 选用和删除执行期间禁用重复操作。搜索键盘弹出后，选用按钮保持在键盘上方。
- 分类读取失败时清除旧分类列表，提供重新加载入口，不把旧数据当成新分类的内容展示。

## 实现边界

没有数据库版本升级或备份格式变化。资料仍通过素材库导入与项目编辑器关联；本轮没有增加向量检索、OCR、自动云同步或自动执行工具。

新增验证位于：

- `test/generation_catalog_test.dart`：父版本分组、筛选编号稳定性、缺失/循环关系、10,000 层版本链，以及参数差异。
- `test/workspace_browsing_test.dart`：最近会话恢复、迟到资料读取、手机资料预览、跨筛选比较、缺图保留参数、跨分类多选、键盘和列表失败恢复。

桌面和手机渲染使用模拟项目与程序绘制的示例图片，不读取个人资料。实际用户图片、真实服务商请求与移动设备人工体验仍需进一步验收。
