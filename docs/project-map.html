03 / 五个模块，明确归属

点击模块可展开职责。模块不等于独立服务或独立安装包。

工作台

负责：会话、任务展示、项目、学习、创作、语音与设置。
拥有：业务内容、偏好和关联。
边界：提交任务和展示结果，不持有模型执行循环。

任务引擎

负责：模型、上下文与缓存、工具循环、有限子任务、取消、任务状态和钩子时序。
拥有：执行记录与结果清单。
边界：调用工具接口，不依赖界面。

工具与扩展

负责：内置工具、MCP、Android 动作和钩子执行。
拥有：连接配置与执行句柄。
边界：返回执行结果，不另建 Agent 循环。

代码工作区

负责：仓库、worktree、文件状态、差异和提交图。
拥有：任务与仓库的绑定；真实状态来自 Git。
边界：电脑执行 Git，工作台展示结构化结果。

设备协作

负责：配对、能力查询、远程任务、事件续传和产物读取。
拥有：设备身份和远程任务引用。
边界：访问指定执行端，不复制第二套任务决策，也不跨设备共享数据库。

一项代码任务的完整流程

选设备与仓库→建任务 Worktree→模型 + 工具 + 钩子→测试与差异→审阅后提交 / 合并

04 / 按用户任务交付

每一步有可运行的结果。源码迁入跟随功能验收推进。

1

两端最小贯通

先比较成熟组件复用。Android + Windows 验证协议、工具、流式和取消；提前试验手机观察/动作。

2

电脑开发任务

CLI、MCP、钩子、worktree 和 Git。加入上下文、缓存与有限子代理对照，完成修改和验证。

3

手机远程工作区

配对与重连；查看文件树、提交图、worktree；审阅并提交。

4

Android 跨 App

观察、操作、回读和停止。完成真实设备验证并确定发行范围。

5

产品迁入与切换

四协议与原有业务、备份和配置迁入。验证数据与回退后替代旧版。
