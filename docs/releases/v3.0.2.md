## Expert Chat v3.0.2

本次更新重构导演故事的写作约束与场景推进流程，并补齐文档处理和会话切换的安全边界。

### 写作流程

- 将故事前提、硬性要求、长期备注编译为稳定且分层的约束块，避免多轮写作时约束漂移或相互覆盖。
- 按“稳定约束 → 全局故事 → 当前场景 → 相关角色/世界信息 → 历史 → 本轮动作”组织提示词，只暴露当前场需要的信息，不提前泄露未来节拍。
- 区分“写下一场”和“续写当前场”：前者推进一个大纲节拍，后者保持当前节拍和场景连续性。
- 长度目标改为软性节奏预算，不再为了凑字数阻止已经完整的场景推进。
- 不再默认强制日轻风格；风格选项按互斥维度合并，保留用户的自由写作要求。
- 新增派生场景状态和提示词预览，方便检查本轮目标、冲突、出场角色及实际发送约束。
- 导演指令识别新增重写、大纲、设定和咨询意图，减少修改请求被误当成续写正文。

### 稳定性与安全

- 修复发送或生图仍在预检时新建会话会复用原空会话、导致后台结果出现在错误视图的问题。
- 可疑或损坏的 OOXML 压缩包现在会硬拒绝，不再以“可编辑附件”回退并传给文档服务。
- 文档改稿拒绝损坏 XLSX 的空工作簿回退，并对服务端返回的下载文件名做路径和控制字符消毒。
- 更新设置页和窄窗口布局回归测试，适配当前完整提示与内容结构。
