# Expert Chat v3.2.0

本次更新开放 Gateway 多账户 OIDC，补齐桌面统一工作区，并修复一批竞态、超时与鉴权问题。

## 多账户 Gateway

- AuthService OIDC + PKCE 登录，Access / Refresh Token 自动刷新。
- Gateway 按账户隔离文件、任务、配额和审计；管理员可在 `/admin` 管理授权。
- 支持 `legacy` / `hybrid` / `oidc` 三种鉴权模式，旧 Token 可平滑迁移。
- 上传地址可与 Gateway 地址分离；能力发现、分类授权与配额检查一并生效。

## 桌面工作区

- 桌面端改为统一侧边栏工作区，聊天、学习和设置共用同一导航。
- 学习 Hub 改版，窄窗口与桌面宽屏布局一致。

## 稳定性

- 删除会话时不再复活仍在预检中的生成；合奏自动播放不会写到切换后的对话。
- 记忆文件读写不再把较新的缓存回滚成旧版本。
- 联网抓页按已校验的 IP 逐个连接，避免 IPv6 首地址失败或错误地把地址列表传给 `Socket.startConnect`。
- 模型请求超时会真正取消连接，避免服务端继续计费。
- Gateway 连接测试带上连接超时；文档上传改为分块落盘，避免超大请求撑爆内存。
- 首次登录并发不再因主键冲突 500；取消中的幽灵任务重启后不再永久占配额。
- 独立文档服务拒绝空 Bearer；legacy Token 比较改为按字节，非 ASCII 令牌不再 500。
- 删除最后一个模型配置时不再丢掉 Gateway 会话等其它设置。

## 自建 Gateway

服务端源码位于 `server/gateway`、`server/doc_edit` 和 `server/authservice`。Docker 构建应从 `server` 目录执行：

```bash
cd server
docker build -f gateway/Dockerfile -t expert-chat-gateway .
```

完整配置见 `server/gateway/README.md`、`server/authservice/README.md` 与 `docs/gateway-architecture.md`。
