# Expert Chat v3.3.0

本次更新让普通对话按本轮任务自动选用提示词，并允许你自己改提示词、增加任务种类。

## 本轮任务类型

- 普通对话发送前，用当前对话模型判断本轮任务类型，只注入对应提示词。
- 出厂种类：通用、写作、代码、翻译、总结。可改名称、选用说明和提示词，也可新增种类。
- 分类器只输出 JSON；种类列表来自你当前的目录。加一条 skill 就是多一个可选种类。
- `/写作`、`/代码` 等前缀优先于自动判断。判断失败回退到「通用」，不阻断发送。
- 助手消息显示「本轮：写作」以及自动 / 已指定 / 回退。
- 故事、乱斗和学习不走这层，避免聊天人设污染其它模式。

> 原先写在「系统提示词（人设）」里的全局文案，现在只作用于普通对话的「通用」种类。故事会话不再自动带上这段人设。
