# Expert Chat v3.4.0

本次更新按 DeepSeek 官方文档对齐 V4 能力，并改进看图、流式排版和提供商配置。

## DeepSeek V4

- 新增官方视觉模型 `deepseek-v4-flash-vision-exp`；已有 DeepSeek 配置会自动加入模型列表。
- 选用视觉模型后可直接发图，不必再单独配置视觉 API。
- 官方 DeepSeek 看图会先走 Files API 上传，对话里用 `file_id` 引用，同一张图在本会话内复用。
- Flash 打开「深度思考」仍使用 flash，只开启思考模式，不再切到 pro。
- `deepseek-v4-flash` / `pro` / `vision-exp` 均可使用提供商官方联网（Responses `web_search`）。
- 深度思考请求会同时发送 `thinking` 与 `reasoning_effort: high`。
- 上下文窗口可设为 1M，回复预留最高 384K（DeepSeek V4 文档上限）。

## 聊天体验

- 流式输出可实时渲染 Markdown；也可在设置中关闭，结束后再排版。
- 对话大纲可跳转到用户轮次和助手回复中的标题。
- 设置中展示当前接口的 token 用量（含缓存命中）。
- 提供商预设覆盖国内、国际和本地常见 OpenAI 兼容端点，可搜索后一键填入。
