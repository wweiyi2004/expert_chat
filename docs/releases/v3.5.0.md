# Expert Chat v3.5.0

本次更新把 API 配置做成可搬家的 JSON，并收口素材库、思考过程、自定义 MCP 和对话默认联网/配图。

## 配置搬家

- 设置 → 数据 → **导出 API 配置** / **导入 API 配置**。
- JSON 含服务商、API Key、搜索、视觉/生图/语音、网关和自定义 MCP 令牌。
- 默认文件名 `expert-chat-settings.json`；仓库已 gitignore，可用 `config/settings.example.json` 填写后导入。
- 导入会覆盖本机密钥和网关；聊天、素材库和长期记忆不动。网关地址变化时会清掉本机旧的登录会话。

## 素材库

- 上传、生图和对话配图都会按规则命名并写入「素材」目录，之后可再选入对话。
- 删除素材前会确认。

## 对话

- 联网 / 配图默认 **自动**，过程显示在思考时间线里，不再堆在输入栏。
- 顶部可切换「对话 | 任务」。
- 自定义 MCP（Streamable HTTP）与文档 MCP 分开；故事/学习模式不露出 MCP 选择。

## 验证

- `flutter test test/settings_bundle_test.dart`：配置导出导入与 OIDC 清理。
- `dart analyze`：新增配置搬家文件无 error。
