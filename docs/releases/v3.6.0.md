# Expert Chat v3.6.0

本次提供完整安装包，包含新增的 Windows 原生预览组件。安装后可继续接收后续 OTA 更新。

## 更新内容

- 新增 HTML / SVG 本地预览：支持源码编辑、运行、刷新、多片段切换与复制；Windows 支持内嵌预览。
- 改进手机布局：输入框独占整行，键盘弹出时收起底部导航，顶栏保留会话标题。
- 改进网页窄屏预览：支持 360 / 390 / 430 像素宽度，补充缺失的视口设置，修复部分 SVG 缩放裁切。
- 统一附件选择：支持最近文件、图片、文档和素材库，改进选择、预览及取消体验。
- 更新 DeepSeek 模型预设与思考控制，改进对话、工具执行、语音和附件处理的稳定性。

## 下载与安装

- **Windows x64**：下载 ZIP，解压后运行 `expert_chat.exe`。
- **Android**：下载通用 APK，支持 arm64、armv7 和 x86_64，沿用原有签名覆盖安装。

本地预览允许内联 CSS / JavaScript，外部网络资源不加载。依赖 CDN 的页面需要改为自包含代码；固定桌面宽度的页面仍需自身提供响应式样式。Windows 内嵌预览依赖 WebView2，组件不可用时可使用预览页的外部浏览器按钮。

新基座版本为 `3.6.0+4108`。旧版用户需要先安装本次完整安装包，后续在“设置 → 关于与更新”接收适用于此版本的 OTA，补丁下载后冷启动生效。
