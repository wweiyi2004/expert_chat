# Expert Chat v3.7.0

- 整包更新增加断点续传、首选与备用下载源、自动切换和文件完整性校验，可配置 Gitee 或其他 HTTPS 镜像。
- 手机移除底部导航，功能与历史会话集中到侧边栏；设置改为分组首页，保留原有主题与颜色偏好。
- 新增多份提示词预设，可保存、编辑、复制并在聊天中快速切换，支持设置导入导出。
- 学习模式增加知识清单、备考计划、每日课程、实际作答反馈与复习安排；学习档案可保存并导出。
- 科研工作区增加 SFTP 文件浏览、文本编辑、上传下载与传输列表，支持终端专注模式。
- 切换页面时继续接收聊天流；Windows 增加托盘，关闭窗口后可在后台运行，通过托盘恢复或退出。
- 思考过程支持滚动预览与展开查看，搜索和浏览步骤按时间线呈现；输入框将文字输入与底部操作区分开。
- 更换为原创猫耳助手图标。
- 包含 Gemini 原生接口兼容、备份迁移、长任务恢复及学习/科研状态处理修复。

Android 使用版本号 `3.7.0+4110`，沿用应用标识与正式签名。这是整包更新，请下载 Android APK 或 Windows ZIP；Windows ZIP 解压后运行其中的 `expert_chat.exe`，保留同目录依赖文件。

更新前可通过设置中的完整备份导出数据。实际后台持续运行仍受设备电池策略、网络及系统限制影响；本次发布未连接 Android 真机进行覆盖升级验收。科研功能保留单个 SSH 连接与多个 tmux 会话，未新增并行多主机或 FTP 协议。

本次在 GitHub 发布；Gitee 同步不作为此次发布的完成条件。
