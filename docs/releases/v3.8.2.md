# Expert Chat v3.8.2

Android 版本为 `3.8.2+4114`。本次发布包含 Android 通用安装包和 Windows x64 完整包。

## 更新内容

- Windows GUI 与 TUI 使用共同的独立 Host，共享会话、工具、任务状态和文件改动。关闭窗口时结束该窗口所属任务，保留历史记录。
- GUI 按项目整理会话，集中显示当前任务状态；文件、成果和代理面板按需展开。
- TUI 补齐文件编辑与运行、Git、旁问和子代理窗口、任务期间补充要求等工作入口。`/workspace` 可查看和修改已有目录规则。
- 优化工具参数、错误反馈、启动连接和任务状态显示。非图片附件以地址引用，图片保留图片内容。
- Android 同步当前共用功能；执行容器与页面生命周期分离，切页不会重建任务。设备控制页显示真实授权状态，并在返回应用后刷新。
- 手机界面区分本机设备、SSH 和远程电脑，按实际执行环境显示文件与终端入口。

## 下载与使用

- `expert-chat-android-universal-v3.8.2.apk`：包含 arm64-v8a、armeabi-v7a 和 x86_64，沿用原签名。
- `expert-chat-windows-x64-v3.8.2.zip`：解压后运行 `expert_chat.exe` 打开 GUI，或运行 `expert.cmd` 使用 TUI。请保留整个目录，后台和文件服务随包提供。
- 模型与服务连接由使用者自行配置；发行包不包含个人配置、凭据或聊天记录。

## 验证范围

32 项移动运行实例、后台生成、分享导入、工作台和窗口生命周期定向检查通过；相关静态检查通过。Windows 打包后的工作台、目录权限、插嘴、附件和窗口退出检查通过。Android 正式包已检查版本号、原签名一致性、三种架构及包内容。

**本次 Android 尚未进行真机安装、运行验证及厂商适配。** Android 仍在手机进程内运行共享执行核心，不保证被系统终止后继续执行。恢复依据已保存的任务记录。

文件校验值见 `SHA256SUMS.txt`，源码版本与构建来源见 `release-manifest.json`。
