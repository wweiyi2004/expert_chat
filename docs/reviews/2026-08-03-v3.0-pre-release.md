## Review findings

### Non-blocking / accepted product choices

1. **导演服从优先级**改为「本轮导演口令 > 硬性说明 > 大纲」。有利于控制感；硬性禁忌仍在冲突时约束口令。测试已覆盖关键路径。
2. **生成方案默认不走 strictReview**。更快首稿；高级用户可在「更多设置」打开。
3. **日轻约束默认注入**会改变旧草稿的 generation fingerprint（空 styleIds 恢复时补 `jp_ln`）。已用「空则默认日轻」处理；带指纹的草稿应在保存时带 styleIds。
4. **`story_ai_assist` 系统提示**相对旧版更短、偏日轻场景。长篇网文密度约束略弱——符合 v3.0 日轻定位。

### Residual risks (post-release backlog)

| # | Risk | Severity | Note |
|---|------|----------|------|
| 1 | 访谈状态不进 local draft JSON | Low | 杀进程时若仍在访谈步，恢复后直接进编辑器（有 premise 才恢复） |
| 2 | 关闭创作模式后仍可从聊天进导演故事 | Info | 有意保留入口 |
| 3 | 日轻公式对非日轻题材仍可能偏对白 | Low | 用户可在更多设置改文风芯片 |
